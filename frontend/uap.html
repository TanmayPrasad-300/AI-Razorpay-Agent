🔐 UAP Mandates

UAP = User Agent Payment mandates. These are delegated spending permissions that a human gives to an AI buyer agent. RazorAgent enforces them before any Razorpay order is created.

What this page represents

When you move the budget slider on Commerce Chat, you are simulating a UAP mandate limit. If an agent tries to buy above that limit, checkout returns GATED_REJECTED.
